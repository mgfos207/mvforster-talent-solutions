# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — raw Tailwind utility classes, no CSS-in-JS/CSS Modules (established Phase 1 convention, verified in `01-VERIFICATION.md`) |
| Icon library | none — inline SVG only (matches existing `AboutHero.tsx`/`Contact.tsx` pattern). Pause/play icon is a hand-authored inline `<svg>` per CONTEXT.md Claude's Discretion. |
| Font | Inter via `next/font/google`, exposed as `--font-sans` (`src/app/globals.css`) — unchanged, no new font added |

**shadcn gate — resolved without asking:** No `components.json` exists and this is a Next.js/React project, which would normally trigger the shadcn init question. Skipped here because CONTEXT.md D-locked phase boundary scopes this phase's *only* new dependency to `ogl` (Claude's Discretion section explicitly lists shader/component structure decisions, none mention a UI/component library), and the verified Phase 1 codebase convention (`01-VERIFICATION.md`, `CONVENTIONS.md`) is deliberately library-free Tailwind with inline SVG — no `clsx`/`cn()`, no component kit. Introducing shadcn now would contradict locked scope and add bundle weight against the perf budget (QUAL-01: Lighthouse ≥ 90, LCP ≤ 2.5s). Registry safety gate is therefore not applicable this phase.

## Spacing Scale

Declared values (must be multiples of 4), consistent with existing Tailwind usage across the codebase (`py-20`=80px, `px-6`=24px, `gap-8`=32px, `mb-16`=64px — all on this scale):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps (pause control internals) |
| sm | 8px | Gap between stacked chooser buttons on mobile |
| md | 16px | Gap between side-by-side chooser buttons on desktop; `scroll-margin-top` buffer above header |
| lg | 24px | Hero content horizontal padding (`px-6`, matches `Services.tsx`/`Expertise.tsx`) |
| xl | 32px | Space between subline and chooser row |
| 2xl | 48px | Space between chooser row and the reserved Phase 3 CTA slot (D-11) |
| 3xl | 64px | Top/bottom breathing room for hero content block on desktop |

Exceptions:
- Pause/play control: minimum **24×24px** hit target (WCAG 2.5.8, per D-13), rendered as a round glass button — visually sized slightly larger (~40px) for comfortable tapping, never below the 24px floor.
- Chooser buttons: stack vertically with `sm` (8px) gap on mobile (`< md` breakpoint); sit side-by-side with `md` (16px) gap at `md` and above (D-09).
- Reserved Phase 3 CTA slot: leave `2xl` (48px) of flexible vertical space after the chooser row; do not build a fixed/bordered placeholder box (D-11 — layout room only, no visible stub).

## Typography

Scoped to new/changed hero elements only. Full sitewide typography system is Phase 4 (CONT-01); existing Phase 1 sizes shown in Heading row for reference/consistency only.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (subline) | 24px desktop / 20px mobile (`text-2xl` / `text-xl`) | 400 (regular) | 1.5 |
| Label (chooser buttons) | 18px (`text-lg`) | 700 (bold) | 1.2 |
| Heading (unused in hero; other sections, Phase 1 reference) | 36px (`text-4xl`) | 700 (bold) | 1.2 |
| Display (headline) | 72px desktop / 48px mobile (`text-7xl` / `text-5xl`) | 700 (bold) | 1.1 |

**Weights used in this phase: exactly 2** — Bold (700) for the headline and the two chooser button labels; Regular (400, Tailwind default/no class) for the subline. No semibold introduced for new hero elements, even though it exists elsewhere in the codebase — kept to the 2-weight budget for this contract.

**Pause control:** icon-only, no visible text label. `aria-label` is screen-reader text, not a sized/visible typography role.

**Headline/subline copy:** D-12 defers exact wording to the plan — Claude drafts 2–3 calm/warm/human, healthcare-focused headline+subline options for user review inside `02-PLAN.md` (removing "technology" and "innovative companies"). This contract constrains the *form*, not the final words:
- Headline: short enough to read as 1–2 lines at 72px desktop without awkward wraps (roughly ≤ 8 words per line).
- Subline: ≤ 2 sentences, plain language, no recruiting/tech jargon, names the healthcare/behavioral-health/healthcare-admin audience.

## Color

### Site-level (established Phase 1, unchanged this phase)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-surface` `#FFFFFF` | Page background outside the hero |
| Secondary (30%) | `--color-brand` `#0B2545` / `--color-brand-strong` `#071A33` | Header, hero block, footer-weight surfaces |
| Accent (10%) | `--color-accent` `#0F766E` (teal) | Section headings (`h3` labels like "Our Services"), small icon accents |
| Second semantic color | `--color-cta` `#E76F51` (coral) | Reserved for the primary conversion action only — not a "destructive" color in this design system; this project has no destructive actions. Not yet active sitewide (Phase 3 Calendly CTA is its first real use). |

### Hero gradient budget (this phase, D-01/D-02/D-03/D-09 — locked)

| Role | Value | Usage |
|------|-------|-------|
| Base/dominant | `--color-brand` `#0B2545`, `--color-brand-strong` `#071A33` | ~70–80% of gradient area; navy wash, kept dark enough everywhere behind the text block to hold WCAG AA contrast for white (`on-brand`) hero text |
| Secondary flow | `--color-accent` `#0F766E` (teal) | ~20–25% of gradient area; slow-moving mid-tone currents, ~20–30s full cycle |
| Glints | `--color-cta` `#E76F51` (coral) | < 5% of gradient area; small, scarce warm highlights only — decorative, never on text or controls |
| Node network | `--color-on-brand` `#FFFFFF` at low opacity | 30–60 nodes (desktop, fewer on mobile) with faint connecting lines; brightens on cursor/touch proximity per D-04 |
| Chooser buttons | `--color-on-brand` translucent fill + border, `--color-on-brand` text at full opacity | Glass/frosted pill buttons; **no coral** (D-09) |
| Pause control | Same glass treatment as chooser buttons | Round button, bottom-right, icon in `on-brand` |

**Accent reserved for:** `--color-cta` (coral) is reserved exclusively for (1) the hero gradient's scarce decorative glints and (2) the Phase 3 "Book an intro chat" CTA, whose layout slot this phase reserves but does not build (D-11). Coral must not appear on the chooser buttons, the pause control, focus rings, or any other interactive element introduced in this phase (D-09). `--color-accent` (teal) is reserved for the gradient's secondary flow and for existing heading/icon accents elsewhere in the site — not introduced as a new interactive-element color in this phase.

**Destructive:** Not applicable — this phase has no destructive actions (pause/resume and anchor-link navigation are both non-destructive and instantly reversible).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (chooser, HERO-05) | Two equal-weight labels, literal per requirement/D-08/D-09: **"I'm hiring"** → `#employers`, **"I'm looking for work"** → `#candidates` |
| Headline + subline | Deferred to `02-PLAN.md` per D-12 — Claude drafts 2–3 calm/warm/human, healthcare-focused options for user review before implementation. Form constraints above (Typography section) apply. |
| Empty state (no-WebGL / reduced-motion / data-saver fallback, HERO-03) | No distinct empty-state copy. The static poster shows the identical headline, subline, and chooser buttons as the animated state — same DOM, same copy (D-05/D-06). There is no reduced-content fallback. |
| Error state (WebGL context loss, HERO-06) | No visible error copy, toast, or banner. The canvas is hidden/removed and the pre-rendered still silently reappears (D-06) — a deliberate "fail invisible" contract matching the project's core value that the page still looks polished if WebGL fails. |
| Destructive confirmation | Not applicable — no destructive actions in this phase. |
| Pause/play control (HERO-04, D-13) | Icon-only button, dynamic `aria-label`: **"Pause background animation"** when playing, **"Play background animation"** when paused. No visible text label. `aria-pressed` (or equivalent state) reflects current state. |
