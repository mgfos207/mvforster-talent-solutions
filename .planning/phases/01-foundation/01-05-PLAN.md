## Contracts this plan creates (Claude's discretion: names and locations, chosen here)

src/types/capabilities.ts (types only, so it is fully erasable):
- `CapabilitySignals` = { detected: boolean; prefersReducedMotion: boolean | null; webgl: boolean | null; saveData: boolean | null; effectiveType: string | null; deviceMemory: number | null; hardwareConcurrency: number | null }. `null` means unknown or the API is unavailable.
- `CapabilityVerdicts` = { canAnimateHero: boolean; canPlayVideo: boolean; canAnimateScroll: boolean }
- `Capabilities` = CapabilityVerdicts & { signals: CapabilitySignals }
- `NetworkInformationLike` = { saveData?: boolean; effectiveType?: string; addEventListener?: (type: "change", cb: () => void) => void; removeEventListener?: (type: "change", cb: () => void) => void }
- `CapabilityEnv` = { matchMedia?: (query: string) => { matches: boolean }; connection?: NetworkInformationLike; deviceMemory?: number; hardwareConcurrency?: number; probeWebGL: () => boolean }

src/lib/capabilities.ts (pure, no React, no DOM globals referenced at module top level, only erasable TS syntax: no enums, no namespaces, no parameter properties; type imports via `import type` with a relative path so Node type-stripping can load it in tests):
- `SSR_DEFAULT_SIGNALS: CapabilitySignals` with detected false and every other field null
- `STATIC_VERDICTS: CapabilityVerdicts` with all false
- `readSignals(env: CapabilityEnv): CapabilitySignals` returns detected true. prefersReducedMotion = env.matchMedia ? env.matchMedia("(prefers-reduced-motion: reduce)").matches : null. webgl = env.probeWebGL(). saveData = env.connection ? Boolean(env.connection.saveData) : null. effectiveType = env.connection?.effectiveType ?? null. deviceMemory = typeof env.deviceMemory === "number" ? env.deviceMemory : null. Apply the same rule to hardwareConcurrency, but treat a value of 0 as null.
- `deriveVerdicts(s: CapabilitySignals): CapabilityVerdicts` uses this rule table (the ONLY place the mapping lives, per D-14):
  - if `!s.detected` → STATIC_VERDICTS (D-16)
  - reducedMotion = s.prefersReducedMotion === true
  - constrainedNetwork = s.saveData === true || s.effectiveType === "2g" || s.effectiveType === "slow-2g"
  - lowEndDevice = (s.deviceMemory !== null && s.deviceMemory <= 2) || (s.hardwareConcurrency !== null && s.hardwareConcurrency <= 2)
  - canAnimateHero = !reducedMotion && s.webgl === true && !constrainedNetwork && !lowEndDevice
  - canPlayVideo = !reducedMotion && !constrainedNetwork && !lowEndDevice   (video does not need WebGL)
  - canAnimateScroll = !reducedMotion && !lowEndDevice   (scroll reveals are tiny and need no bandwidth, so they are not network-gated)

src/hooks/useCapabilitySignals.ts ('use client'):
- `useCapabilitySignals(): CapabilitySignals` is implemented with React 18 `useSyncExternalStore(subscribe, getSnapshot, getServerSnapshot)`, where getServerSnapshot returns SSR_DEFAULT_SIGNALS (D-16). useSyncExternalStore is chosen over useEffect+setState because eslint-plugin-react-hooks v7 (shipped with eslint-config-next 16) flags setState inside effects, and it is the idiomatic React API for subscribing to browser state.

src/providers/CapabilitiesProvider.tsx ('use client'):
- `CapabilitiesProvider({ children }: { children: React.ReactNode })`
- `useCapabilities(): Capabilities`. Outside a provider it returns `{ ...STATIC_VERDICTS, signals: SSR_DEFAULT_SIGNALS }` (fail-static, consistent with the core value that the page works when enhancements fail) instead of throwing.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser APIs → app state | Values from navigator.connection, deviceMemory, and matchMedia are untrusted, client-controlled hints |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | Spoofed navigator hints | accept | Hints only choose between enhanced and static presentation. A spoofed value can at worst give that visitor animation or static content on their own device. No security decision depends on it. |
| T-05-02 | Denial of Service | WebGL probe | mitigate | Probe once per page load (module cache) inside try/catch, and release the context immediately via `WEBGL_lose_context`. This avoids exhausting the browser's context limit before Phase 2's hero creates its own. |
| T-05-03 | Information Disclosure | Fingerprinting signals | mitigate | Signals stay in memory only. No storage (D-13 forbids localStorage), no network transmission, no analytics. The grep gate asserts there is no `localStorage`. |
| T-05-04 | Denial of Service (hydration) | SSR/client mismatch | mitigate | `getServerSnapshot` returns `SSR_DEFAULT_SIGNALS`, so the server HTML and the hydration render match (D-16). The client value applies after hydration. |
</threat_model>
